# Decision document

## 1. Scope of version one

- **Decision:** Build version one as a single-screen PDF resume analyzer targeting 4 fixed developer roles.
- **Options considered:**
  - Single-screen PDF analyzer with 4 fixed entry-level developer roles (e.g., Frontend, Backend, Full-Stack, Software Engineer).
  - Multi-page application with user accounts, saved resume history, and custom job description matching.
  - Multi-format file uploader supporting PDF, DOCX, and plain text with an interactive resume editor.
- **Chosen:** Single-screen PDF resume analyzer targeting 4 fixed developer roles.
- **Why:** Keeps version one focused on fast, actionable feedback for final-year students applying for their first developer job without the complexity of authentication, storage, or multi-format parsing.
- **Revisit when:** Core PDF analysis quality is validated with students and users ask for custom job descriptions, DOCX support, or tracking revisions over time.
